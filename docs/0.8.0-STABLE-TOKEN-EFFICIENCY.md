# Heliolune 0.8.0: stable token-efficiency boundaries

English · [简体中文](0.8.0-STABLE-TOKEN-EFFICIENCY.zh-CN.md)

Build identity: `0.8.0+codex.20260818153255`

Heliolune 0.8.0 promotes Native V2 to a stable release after measuring the Sol controller, the zero-model terminal path, and release validation. The machine-readable companion is [`benchmarks/results/0.8.0-stable-token-efficiency.json`](../benchmarks/results/0.8.0-stable-token-efficiency.json).

## Measured findings

- The observed long Sol task recorded 71,502,261 input tokens, of which 70,178,816 were cached (98.15%). The remaining hotspots were task length, 615 sampling records across 9 user turns, and 405 single-call wrappers out of 468 (86.54%). These are diagnostic rollout counters, not provider billing.
- HelioTerm processed 1,485,884 bytes and returned 833,431 compact bytes, saving 652,453 bytes (43.9%). Its bytes/4 method estimates 163,065 net content tokens saved and records 80 avoided wakeups/model boundaries; this estimate is not billing.
- A successful full release validator exposes 18,538 bytes. `-Compact` still runs all 205 tests but exposes 65 bytes, a measured reduction of 18,473 bytes (99.65%). Failures retain the last 40 lines, capped at 8 KiB.
- The accepted engineering owner is proven from persisted Native V2 metadata as `gpt-5.6-luna` with `max` effort. Across two bounded turns it used 9 tool calls, a 7,025-byte maximum result, and 18,146 cumulative tool-output bytes.

## Stable policy

- Sol batches distinct acceptance checks, does not rerun `verification.owner`, and prefers compact HelioTerm evidence.
- Release packaging invokes compact validation automatically.
- Pure version and release-note propagation remains Sol-owned; Luna ownership is reserved for bounded engineering and repair where cached implementation context is useful.
- Historical alpha.3 and alpha.4 measurements remain unchanged. This release does not convert diagnostic counters into billing claims and does not claim that forward-looking controls saved past Sol input.

## Verification

The compact validator passed the complete suite under PowerShell 7 and Windows PowerShell 5.1. A synthetic 1,000-line failure also exited nonzero while retaining a bounded diagnostic tail.
