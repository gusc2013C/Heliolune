# 0.6.5 real-demo validation

English · [简体中文](0.6.5-REAL-DEMO.zh-CN.md)

## Release gate

The 0.6.5 candidate was not accepted after a single happy-path run. Testing began with the installed 0.6.4 plugin and continued in a fix-and-restart loop until the final code passed the automated suite and every supported real-demo lane below. A failed run never counted as evidence of success.

The initial installed 0.6.4 four-way demo ran for about 5 minutes 48 seconds before the process owning the job exited. Later candidates exposed a normal-completion app-server leak, an intermittent detached-runner exit, partial claim visibility, a POSIX shutdown gap, and a Windows sharing violation between the WPF reader and terminal JSON replacement. The final implementation detaches job ownership, publishes complete claims atomically, keeps the runner referenced, closes child process trees, reads status with delete sharing, retries bounded transient replacements, and proves cleanup by PID.

This matrix covers default and maximum read concurrency, queue reuse, token-first fallback, isolated writes, independent terminal delivery, visible Windows status, automatic UI closure, long-running ownership, and resource cleanup. It does not prove that all future repositories, model outputs, host versions, or external failures are defect-free; it establishes that no remaining usage-level defect was observed across the supported release scenarios exercised here.
