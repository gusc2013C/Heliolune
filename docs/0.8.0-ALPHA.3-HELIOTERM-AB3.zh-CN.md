# Heliolune 0.8 alpha.3：HelioTerm 三路实测

[English](0.8.0-ALPHA.3-HELIOTERM-AB3.md) · 简体中文

2026-08-08 使用同一代码快照、同一 Spark 模型（medium）、同一条命令和同一组 23 个测试，比较了普通终端、直接 HelioTerm 与 MCP HelioTerm。三种成功路径的质量一致，均为 23/23 通过。

受控独立 Spark session 中，普通终端总 token 为 31,350；直接 HelioTerm 为 31,925（+1.83%）；最小配置 MCP 为 38,619（相对直接模式 +20.97%）。MCP 把 2,060 字节原始输出压缩为 41 字节，模型可见输出减少 98.01%，未缓存 input 减少 23.18%，墙钟减少 26.18%；但延迟工具发现增加了缓存工具上下文，所以总 token 反而上升。

真实 Desktop 编排中，根任务直接运行使用 61,825 total token、12.057 秒；根任务加直接 HelioTerm 使用 172,592 total token、26.450 秒，分别增加 179.16% 和 119.37%。当前 Desktop Native V2 子代理没有获得本地 `helioterm.run` MCP 工具，失败样本回退到普通终端并失败；角色现已改为工具不可见时 `FAIL|calls=0|mcp-unavailable`，禁止回退。

因此 alpha.3 保留 HelioTerm 为默认包含的独立组件。普通 terminal 工作走 direct `model=0` 路径且不创建子任务；只有显式请求语义 terminal 工作时才使用 Luna/high 模型 HelioTerm leaf。MCP 维持实验性，不作为默认路径。完整机器证据位于独立 HelioTerm 仓库的 `benchmarks/results/0.1.0-alpha.1-ab3.json`。
