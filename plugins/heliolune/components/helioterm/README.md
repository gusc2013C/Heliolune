# HelioTerm

HelioTerm is the independently usable semantic-terminal component bundled with Heliolune by default. Its stable implementation entry points are `direct-runner.mjs`, `firewall.mjs`, `inspect-proof.mjs`, and `preflight.mjs`. The ordinary runner can combine up to four bounded observations into one process and one compact result; adjacent read-only observations execute concurrently. Compatibility launchers remain under `plugins/heliolune/scripts/` during the alpha series.

The component is model-bound rather than model-named. `plugins/heliolune/model-bindings.json` selects the Codex role, model, and effort. Persisted proof must match all three values; unsupported or unavailable model ids fail when Codex Desktop attempts to create the role.
