# Heliolune 0.6.2 fast-start benchmark

English · [简体中文](0.6.2-FAST-START-BENCHMARK.zh-CN.md)

This low-token deterministic benchmark repairs `mergeMaintenanceWindows` from the same Git baseline. The public suite has four tests; a separate evaluator adds eight hidden contract and immutability cases. Both arms reached 12/12.

| Arm | Correctness | Wall time | Model usage | Estimated model cost |
|---|---:|---:|---:|---:|
| Sol-only Codex task | 12/12 | 123.532s | Sol 120,374 input / 4,469 output; 96,768 cached | 7.512100 |
| Heliolune 0.6.2 engine | 12/12 | 127.451s | Luna 126,833 input / 5,290 output; 74,496 cached | 0.457633 |

Heliolune was 3.17% slower in wall time (`0.969x`) while its worker-side model cost was 93.91% lower. That cost percentage is not an end-to-end Codex-session saving: the Heliolune arm used the release harness, so it had no billed Sol controller turn. The MCP's history-calibrated projection was 1.877557 Sol-only units and 75.6261% directional savings. A fresh installed-plugin task is still required to measure the reduced Sol controller prefix end to end.

The default `start_task` created four active streams. The mutating owner completed in 109.723s; edge and correctness reviews completed, while the contract review returned an honest partial result. Deterministic integration applied only `src/merge-windows.mjs`, and both public and hidden suites passed. A read-only companion no longer blocks a completed writer merely because its report is partial or times out.

Startup work was measured by serialized character count divided by four. The hot-path skill fell from approximately 3,173 to 1,096 tokens (−65.5%). The default installed pool tool surface fell from approximately 1,586 to 1,192 tokens; the normal `start_task` schema alone is approximately 455 tokens. Skill plus installed pool schema fell about 51.9%, excluding the unchanged independent await schema.

The earlier 0.6.1 Heliolune task is excluded. Its task-local tool registry did not expose the plugin MCP, after which Sol searched cache directories and manually launched a short-lived server. That measured a host/setup failure, not Heliolune execution. Version 0.6.2 now fails fast when either required tool is absent.
