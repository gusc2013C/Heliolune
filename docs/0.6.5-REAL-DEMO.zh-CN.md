# 0.6.5 真实 demo 验证

[English](0.6.5-REAL-DEMO.md) · 简体中文

## 发布门禁

0.6.5 候选版没有因为一次 happy path 成功就被接受。测试从已安装的 0.6.4 插件开始，持续执行“发现问题—集中修复—从头重跑”，直到最终代码同时通过自动化套件和下列全部受支持真实 demo。失败轮次绝不计入成功证据。

最初的已安装 0.6.4 四路 demo 运行约 5 分 48 秒后，持有 job 的进程先退出。后续候选版又暴露了正常完成后的 app-server 泄漏、detached runner 间歇退出、claim 部分可见、POSIX 关闭缺口、同版本旧 MCP 残留、静默 worker 无限续租，以及 Windows 状态/终态记录竞态。最终审计中，job `993ad283` 已完成，但 benchmark 在窗口读取终态前删除了临时 job root，用户看到的窗口因此停留在最后一帧 running 状态。该精确窗口已关闭，benchmark 改为 headless，生产窗口也会在记录消失时失败收口。

最终 `0.6.5-owner-heartbeat-r2` 要求 pool/request/await 三端精确构建身份；每 5 秒独立写 owner 心跳，30 秒陈旧 owner 失败，连续 4 次无 app-server 活动则中断；claim 原子发布；Windows 进程树结束后等待 app-server 退出确认；终态替换可抵御瞬时冲突；所有终态或不可恢复窗口状态都进入 15 秒关闭路径。
