# 0.6.5 真实 demo 验证

[English](0.6.5-REAL-DEMO.md) · 简体中文

## 发布门禁

0.6.5 候选版没有因为一次 happy path 成功就被接受。测试从已安装的 0.6.4 插件开始，持续执行“发现问题—集中修复—从头重跑”，直到最终代码同时通过自动化套件和下列全部受支持真实 demo。失败轮次绝不计入成功证据。

最初的已安装 0.6.4 四路 demo 运行约 5 分 48 秒后，持有 job 的进程先退出。后续候选版又暴露了正常完成后的 app-server 泄漏、detached runner 间歇退出、claim 部分可见、POSIX 关闭缺口，以及 WPF reader 与终态 JSON 替换之间的 Windows 文件共享冲突。最终实现把 job ownership 完全分离，原子发布完整 claim，保持 runner 引用，关闭子进程树，以 delete sharing 读取状态，对瞬时替换冲突做有界重试，并通过 PID 证明资源回收。

| 门禁 | 最终结果 | 直接验收证据 |

该矩阵覆盖默认与最大读取并发、队列复用、token-first 回退、隔离写入、独立终态交付、Windows 可见状态、界面自动关闭、长任务 ownership 与资源回收。它不能证明未来所有仓库、模型输出、宿主版本或外部故障绝对无缺陷；它证明本次覆盖的受支持发布场景中没有再观察到使用层问题。
