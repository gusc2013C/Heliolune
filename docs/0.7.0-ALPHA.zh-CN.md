# Heliolune 0.7.0 alpha 评估

[English](0.7.0-ALPHA.md) · 简体中文

`0.7.0-alpha.1` 把路线图中有证据支持的 0.6.6/0.8 部分提前实现为可审计实验：自适应 1/2/4 路 worker、speed-first 旁路 shadow 决策，以及 `TASK_NODE_V1` 执行遥测。本版本不声称低并发一定更快。

## 实现内容

- `start_task` 默认使用 `adaptive`。低风险精确文件任务选择单 owner；中等有界任务选择 owner 加边界/测试审查；宽 scope、目录 scope、高风险或保留边界仍使用成熟的四路方案。
- `profile=speed-first` 保留为显式四路对照，仍适合彼此独立的宽任务；`profile=token-first` 继续作为安全回退。
- 单路和双路写入使用与四路相同的 detached-worktree 安全集成 gate。
- speed-first 运行会记录未执行的 adaptive shadow 决策，便于后续比较。
- 终态结果增加带版本的 task-node 时序、路由信号、排队时间、worker 总时长、关键路径、利用率和 Leader 占比。MCP 边界看不到的指标明确标为 unavailable，不进行猜测。
- 已完成、低风险的单/双路自适应任务可以直接返回；高风险、未完成、需要 Sol 或不安全集成仍会唤醒共享 Leader。

## 真实匹配结果

所有 arm 都在同一 checkout 上真实运行 GPT-5.6 Luna/max。数字是 worker 边界估算，每个 arm 目前只有一个样本。

| 匹配任务 | 对照 | Adaptive | 墙钟变化 | 估算费用变化 |
|---|---:|---:|---:|---:|
| 窄范围有界审查 | 4 路，160.253s，0.588295 | 1 路，112.371s，0.081278 | **-29.88%** | **-86.18%** |
| 中等有界审查 | 4 路，254.321s，0.562255 | 2 路，263.399s，0.354365 | **+3.57%** | **-36.97%** |

窄任务在保持相同证据/风险验收形态的同时大幅减少重复工作。双路任务降低了 token 与估算费用，但其中一个 worker 长尾达到 243.488 秒，所以比四路对照更慢。该负结果被完整保留：它说明当前路由仍是 alpha，也说明必须保留显式 speed-first。

独立的 8 项审计基线还显示：四路 speed-first 为 51.371 秒，串行为 163.163 秒，在同为 0.975 质量下加速 3.176 倍。因此 adaptive 对宽且独立的 scope 继续选择四路。

## 发布闸门与局限

确定性测试必须覆盖分类边界、1/2/4 调度、直接返回与 Leader 路由、遥测、安全写隔离、运行身份和终态回收；安装态宿主测试还必须证明仅启动一次、等待一次、窗口自动关闭、runner 退出及 app-server 退出。

最终门禁在 Windows PowerShell 5.1 与 PowerShell 7.6.4 下均通过 111/111 测试。全新安装态宿主运行选择单个 adaptive worker，44.463 秒完成，输出 `TASK_NODE_V1`，显示中文状态，原生窗口自动关闭，runner 与 app-server 进程树全部退出。另一次真实双 writer smoke 在 62.253 秒内从 detached worktree 安全应用 `alpha.txt` 与 `beta.txt`，index 保持 unstaged，临时 worktree 全部删除，runner 正常退出。

安装后的 MCP 工具面约为 1,166 schema token；常规 `runtime_info` + `start_task` 路径约 495 token，比保留的 0.6.4 测量值 480 增加 3.13%。这 15 token 用于 adaptive profile 字段与路由说明；高级 batch schema 仍约为 447 token。

当前真实样本不足以支持普适耗时结论。controller 规划/最终验收 token、错误验收率、route regret、重复探索率和结果实际采用率仍不可观测。稳定版 0.7 之前应对匹配 arm 做多次随机化重复，并结合 shadow 决策比较预测路由与实际路由。

原始证据：[`benchmarks/results/0.7.0-alpha.1-adaptive-r1.json`](../benchmarks/results/0.7.0-alpha.1-adaptive-r1.json)。
