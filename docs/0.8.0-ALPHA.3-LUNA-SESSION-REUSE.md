# 0.8.0 alpha.3: Luna default execution and bounded session reuse

English · [简体中文](0.8.0-ALPHA.3-LUNA-SESSION-REUSE.zh-CN.md)

## Current policy

- Ordinary HelioTerm commands continue through the deterministic direct runner and consume `model=0`.
- A model-backed terminal role is created only when semantic terminal work is explicitly required; HelioTerm and HelioTerm MCP use `gpt-5.6-luna/high`.
- The old `spark_terminal` name remains only for compatibility; its active binding is also Luna/high.
- Engineering owner, peer, and critic roles continue to use Luna/max.
- A Luna owner may be reused for at most three turns while contractId, objective, scope, reserved decisions, branch, and worktree are unchanged: implementation, focused repair, and evidence recovery. Any boundary change requires a new owner.
- Model-backed HelioTerm may be reused for at most eight requests in one parent task; each request allows at most four tool calls and request/response limits are 64/256 UTF-8 bytes.

## Why these limits

The current official price table lists Sol input/cached-input/output at 125/12.5/750 and Luna at 5/0.5/30, a 25:1 ratio across all three billing categories. Commands that need no model still use direct execution because zero model calls are cheaper and faster than any model.

In one real Native V2 Luna owner session, the first turn had no cached input; reuse accumulated 128,776 input tokens and 107,008 cached input tokens, an 83.10% cache rate. That result demonstrates stable-prefix reuse, not a universal project-wide rate, so the implementation keeps a hard three-turn limit and requires later turns to submit the same contract's `HELIOLUNE_OWNER_FOLLOWUP_V1`.

## Acceptance boundaries

Reuse reduces repeated discovery and startup cost, but Luna's self-reported result is not acceptance. Sol independently checks actual changed paths, the diff, and acceptance checks; persisted rollout proof must still establish model, effort, Native V2, parent/child relationships, tool budgets, and no fallback. A proof that observes Terra, Spark, or another binding must fail.
